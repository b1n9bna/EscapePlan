## 💡 为什么需要 EscapePlan？

无论是程序员、设计师、咖啡师、护士幼教、电工技工、还是刚毕业的大学生，“**全球移居 / 海外生活 / 数字游民 (Digital Nomad) / 寻找人生平替**” 是这个时代普通人最真诚的探索之一。

然而，网络上的信息环境却充斥着虚妄：
- **中介垄断与焦虑收割**：90% 的移居攻略都是中介写的营销号软文，故意把官方免费通道包装成几十万的黑盒付费服务；
- **盲目神化与现实脱节**：只吹汇率和阳光海滩，闭口不提海外沉重的所得税、国民医保、看病排队与无聊寂寞的文化休克；
- **行业视角过窄**：很多人以为只有搞计算机才能出国，实际上各国的**蓝领技工、护理幼教、自由职业、打工度假(WHV)、非盈利居留**门槛完全不同。

**EscapePlan 旨在通过开源与游戏化模拟的力量，让每一个人都能以最有趣、最透明、最硬核的方式推演自己的全球移居平行宇宙。**

### 1. 🎮 平行人生：全球移居 5 年宿命模拟器 (Inspired by 1in8b.life)
- **多行业全覆盖**：程序员、咖啡师/西点师、护士/护理员、电工水管工蓝领技工、幼教中文老师、视觉设计师、跨境运营、应届毕业生、自由游民。
- **随机开局抽盲盒**：一键随机抽取姓名、年龄、启动资金（5万穷游到150万中产）与外语天赋。
- **按年推进的真实抉择**：
  - 从第 1 年租房审查与文化休克、第 2 年除夕夜老中胃大爆发、第 3 年职场破局、到第 5 年永居终审；
  - 实时联动**身心健康、现金储备、语言能力、身份进度、老中胃指数**五大核心数值。
- **生成极具分享欲的【人生纪念结算卡】**。

### 2. 🧭 移居精神体检罗盘 (Escape Compass)
- 5 道充满梗、直击灵魂的生活场景测试（老中胃依赖、好山好水好无聊抗性、行政磨叽高血压抗性、内卷做题家基因、税收拔毛心疼指数）。
- 诊断你到底属于“纯度 100% 的原生老中（建议退订机票安心摸鱼）”，还是“精神东亚卷王”、“精神北欧人”或“赛博吉普赛游民”。

### 3. 📚 签证 Subclass 深度图谱与交互算分器
- **🇯🇵 日本**：高度人才专门职 1号 (70分/80分急速永住交互打分器) + 普通技人国工签 + 2024新版特定活动数字游民签。
- **🇦🇺 澳大利亚**：WHV 462 打工度假签证 + 紧缺幼教/护理/蓝领技工 189/190 绿色通道。
- **🇪🇸 西班牙**：非盈利性居留 (No Lucrativa - 存钱即可移居，废除移民监) + 数字游民 DNV。
- **🇩🇪 德国**：2024新版“机会卡 (Chancenkarte)” 6分制官方找工签算分器 + 欧盟蓝卡 IT 降门槛通道。
- **🇹🇭 泰国**：2024全球爆款 DTV (Destination Thailand Visa) 5年多次数字游民签（10万存款流水）。
- **🇨🇦 加拿大**：BC PNP Tech 科技定向通道 + Express Entry 联邦技术移民。

### 4. 💰 现实推演沙盒 (Reality Check)
- 精准扣除东京、悉尼、柏林、温哥华、清迈、瓦伦西亚的严苛所得税与社保年金，算出**每月实打实能留在手里的净存现金 (Net Savings)**。
- 换算国内一线生活品质等价物对冲（*“在悉尼年薪 9.5 万澳币，生活宽裕度约等于在上海/北京税后月净入 2.7 万元”*）。

### 5. 🛠️ 手搓 DIY 路线图 (DIY Action OS)
- 整理各国国内公证、**海牙认证 (Apostille)**、官方网申递签、以及抵澳/抵日/抵德抵西落地前两周办卡落户指南。
- 附带社区血泪避坑警示，支持在浏览器本地勾选记忆，一键**导出为 Markdown 备忘录**。

## 🛡️ 隐私与开源承诺

1. **100% Local-First**：所有测试选项、模拟记录与算分数据**完全保留在您的本地浏览器 LocalStorage 中**。
2. **零服务器追踪**：本项目不部署任何后台数据采集服务器，不收集任何个人隐私，绝无商业销售骚扰。
3. **零商业广告**：不接受任何移民中介商业赞助或付费导流。

## 🛠️ 本地开发与运行

本项目采用纯静态架构，基于 **React + TypeScript + Vite + Tailwind CSS** 构建：

```bash
# 1. 克隆代码仓库
git clone https://github.com/b1n9bna/EscapePlan.git
cd EscapePlan

# 2. 安装项目依赖
pnpm install

# 3. 启动本地开发服务 (支持极速热更新)
pnpm run dev

# 4. 构建纯静态导出包 (可部署至任何静态托管)
pnpm run build
```
